# 📁 Python File Organizer

A Python command-line application that automatically organizes files into folders based on their file types.

Instead of manually sorting files, this tool detects the file extension and moves each file into the appropriate category folder.

---

## 🚀 Features

- 📷 Organize images
- 📄 Organize documents
- 📊 Organize spreadsheets
- 📽️ Organize presentations
- 🎬 Organize videos
- 🎵 Organize music
- 📦 Organize archives
- 🐍 Organize Python files
- 💻 Organize programming files
- 📁 Handle unknown file types
- 🔄 Automatically avoid duplicate filenames
- 🛡️ Error handling
- 🧪 Automated tests
